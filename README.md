# Hồ sơ tài liệu

20 tài liệu: 15 ảnh, 2 ghi âm, 3 video. Trang hỗ trợ vuốt ngang trên điện thoại, phóng to ảnh, phát media và tải gốc.

Ghi âm TL-011 được lưu thành 4 phần do giới hạn tải lên. Bấm Nạp ghi âm để web ghép nguyên vẹn và đối chiếu SHA-256 trước khi nghe/tải. Xem manifest.json để đối chiếu file nguồn.

Vercel: import repo, Framework Preset Other, không có build command, để Output Directory mặc định. Cần bảo vệ quyền truy cập cả trang và media trước khi chia sẻ. Repository private không tự làm website private.

Đã đối chiếu mã Git blob của toàn bộ media với bản sao trên máy. Chưa kiểm tra phát media trên website triển khai hoặc nghe/xem toàn bộ nội dung.
