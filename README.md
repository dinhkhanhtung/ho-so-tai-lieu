# Hồ sơ tài liệu

Trang xem trên điện thoại: mỗi nhóm vuốt ngang, ảnh phóng to, ghi âm/video có nút phát và tải gốc.

20 tài liệu: 15 ảnh, 2 ghi âm, 3 video. TL-011 được lưu thành 3 phần do giới hạn tải lên; trang ghép lại đúng thứ tự, đối chiếu SHA-256 trước khi cho nghe/tải. File tái tạo giữ nguyên byte so với nguồn. Danh mục tại manifest.json.

Triển khai Vercel: import repo, Framework Preset Other, không có build command, Output Directory để mặc định. Bảo vệ cả trang lẫn media bằng kiểm soát truy cập thực sự trước khi chia sẻ. Repo private không tự làm website private.

Chưa kiểm tra phát media trên web triển khai hoặc nghe/xem toàn bộ nội dung. Không kết luận sự việc.
